# 实验 8：串联流动反应釜停留时间分布数据处理

维护者：**lsj**。本程序面向脉冲示踪法的单釜与串联釜电导数据。把仪器导出的文件交给一个 Python 脚本，它会完成水电导背景估计、响应起点识别、停留时间分布计算和作图。用程序独立计算和出图时不必打开 Origin。

24 级《化工基础实验》将该实验列为**实验八**。讲义的“实验数据与处理”要求用 Origin 作 `c(t)~t` 响应曲线和 `E(t)~t` 曲线，并通过积分或离散化求平均停留时间、方差及模型参数 `N`。本程序可独立完成相应数值计算与图像输出；如果教师要求按讲义使用 Origin 或提交 Origin 工程文件，请另行满足该要求。本项目不包含原仓库的源代码或原始讲义。

## 它能做什么

输入一份或多份 CSV、TSV、XLSX 数据文件，或内部实际为 XLSX 的 `.xls` 仪器文件。程序自动在前 30 行寻找表头，识别时间列与电导列；以第一电导探头的响应为准寻找时间零点，并从此前稳定数据估计各探头的水电导。随后逐点扣背景，计算相对浓度响应、`E(t)`、`F(t)`、平均停留时间、方差和模型参数 `N`。

运行后得到结果总表 `results.csv`、可供检查的逐点 CSV，以及 `c_t.png`、`E_t.png`、`F_t.png` 三张图。原始文件不会被改动，也不需要 JSON 配置。`c_t.png` 是由扣除水背景后的电导换算出的**归一化相对响应**，不是经浓度标定的绝对 `c(t)`；作业若要求绝对浓度曲线，需有独立的电导-浓度标定。程序不生成 Origin 工程文件。

## 三步运行

1. 安装 Python **3.10 或更新版本**，打开终端并进入本程序所在目录。
2. 安装绘图依赖：

   ```bash
   python3 -m pip install -r requirements.txt
   ```

3. 把数据文件路径直接交给程序；单釜、三釜可以一次处理：

   ```bash
   python3 rtd.py --time-unit s "单釜.xls" "三釜.xls"
   ```

Windows 若用 `py` 启动 Python，把命令里的 `python3` 换成 `py`。文件名或路径含空格时保留引号。默认在**第一份输入文件旁**创建 `rtd_results/`，也可用 `-o 结果目录` 指定位置。`--time-unit s` 只负责图表标签；若原表没写时间单位，请先核实，不能因示例使用秒就认定自己的数据也是秒。省略此参数时图中标为 `recorded unit`。

想先试运行，可用包内的**人工示例**：

```bash
python3 rtd.py --time-unit s -o sample_results examples/demo_three_tanks.csv
```

Mac 用户也可双击 `run_sample.command` 运行示例。示例的预设响应起点为 50 s，三个水电导为 100、80、75；它不是任何同学的实测数据。

## 实验 8 的注意点

1. **电导不是浓度。**先减去注入前的水电导，才把校正电导当作浓度的比例信号；`c_t.png` 画的是 `c(t)/c_max`，不是绝对浓度。
2. **自动找到的是第一探头的可观测响应起点。**文件中若未记录实际注射瞬间，程序无法证明两者相同。计算平均停留时间前，最好与实验记录核对。
3. **第一电导列应是最先响应的探头。**多探头按原表列顺序处理；若表格列顺序不是沿流向排列，先调整表格再运行。支持常见的“时间”/`Time`/`t(s)` 和“电导”/`conductivity` 列名；无法识别时会报错。
4. **要看曲线尾部。**程序不做背景漂移修正，也不补测量结束后的尾部。末点信号仍明显时会提示；若算得 `N<1`，不要把它解释为理想串联釜的实际釜数。

计算要求时间严格递增、无重复且等间隔采样。真正的旧版二进制 `.xls` 需先另存为 XLSX 或 CSV。结果目录必须与原始文件所在目录不同，以防覆盖原始数据。

## 计算依据与结果含义

设仪器记录的电导为 `κ_i`，程序估计的水电导为 `b`。按 `Δκ_i=max(κ_i-b,0)` 校正，并在 `c_i∝Δκ_i` 的条件下用等时间间隔的离散式计算：

```text
c_i/c_max = Δκ_i/Δκ_max
E_i       = Δκ_i / Σ(Δκ_i Δt)
t̄        = Σ(t_i Δκ_i) / ΣΔκ_i
σ²        = Σ(t_i² Δκ_i) / ΣΔκ_i - t̄²
N         = t̄² / σ²
```

`t` 从识别出的响应起点算起，包含峰前上升段、峰值和下降段；不是从最大值开始积分。`F(t)` 是 `E(t)` 的梯形累计积分。逐点 CSV 保留原始电导、背景、校正信号、相对浓度、`E(t)` 和 `F(t)`，便于自己复查每一步。`results.json` 是与总表等价的机器可读输出，**运行时自动生成，不是输入配置文件**。
